# Random-password-generator

## Description
This is a simple Python project that generates a random password
according to the length entered by the user.

## Features
- Takes password length from the user.
- Generates a random password.
- Uses letters, numbers and special characters.
- Handles invalid input.
- Ensures that the password length is greater than 0.

## Technologies Used
- Python
- random module
- string module

## How to Run
1. Open the project in VS Code.
2. Run the Python file.
3. Enter the required password length.
4. The program generates and displays the password.

## Example

Enter your password length: 10

Your password is:
aB7@kP2!xQ
