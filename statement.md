# Project Statement

## Problem Statement

Creating a strong password manually can take time, and users may also choose simple passwords that are easy to guess. This project is made to generate a random password based on the length entered by the user.

## Scope of the Project

The project can be used to generate random passwords of different lengths. It uses letters, numbers and special characters to create the password. The program also checks the input given by the user and asks for a valid number if the input is not correct.

## Target Users

This project can be used by anyone who wants to generate a random password quickly. It can be useful for students, beginners and general users who need a randomly generated password.

## High-Level Features

- Takes the required password length from the user.
- Generates a random password.
- Uses uppercase and lowercase letters.
- Uses numbers and special characters.
- Handles invalid input using error handling.
- Checks that the password length is greater than zero.
- Displays the generated password to the user.
