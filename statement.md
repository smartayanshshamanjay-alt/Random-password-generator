# Project Statement

## Problem Statement

Creating a strong password manually can take time, and sometimes users may create simple passwords. This project is made to generate a random password using Python. The program takes the required password length and creates a password using different types of characters.

## Scope of the Project

The project can be used to generate passwords of different lengths. It uses lowercase letters, uppercase letters, numbers and special characters. The program also checks the entered length and handles invalid input.

## Target Users

This project can be used by students, beginners and normal computer users who want to generate a random password easily.

## High-Level Features

- Enter the required password length
- Check whether the input is valid
- Use lowercase and uppercase letters
- Use numbers and special characters
- Generate a random password
- Make sure all required character types are included
- Shuffle the password characters
- Display the generated password
